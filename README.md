# Git в эпоху AI: учебный репозиторий

Изолированный пример для подготовки видео Тимура Чеберды. Создан AI-ассистентом с разрешения владельца.

История показывает ветвление, объединение, намеренный конфликт и обратный коммит. Ошибки в истории созданы специально для обучения, это не реальные инциденты и не наблюдения за поведением другой модели.

`index.html` - статическая учебная страница. Кнопка не отправляет заявку: серверной части, платежей и клиентских данных здесь нет. Изменение надписи не доказывает работоспособность сервиса записи.

Цель PR: видеть небольшую правку, её назначение и пределы проверки. Никаких ключей, личных материалов или зависимостей проект не содержит. Конкретная модель AI не является условием использования примера.
